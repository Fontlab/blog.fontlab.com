With [FontLab Pad 2](https://www.fontlab.com/fontlab-pad/), you open a font without installing it, type your text, dial a variable font to the exact style you want, and copy the result into your favorite app. It has been free for ten years, and it still is!

A variable font holds hundreds of styles. A color font brings its own palette. Your document app shows you what it supports, which is rarely all of it.

FontLab Pad is the room where you get the text right first. Open a font file or an installed font. Type. Choose an instance, or move the axis sliders. Copy as Bitmap, SVG or PDF, or export a PNG, SVG or PDF file to place in your design.

## Variable fonts, at any instance

Pad 2 previews variable OpenType fonts at their predefined named instances and at any in-between location you like. It also interpolates multiple-master Type 1 fonts. If a font has no predefined instances, you choose masters instead.

Predefined instances live in the sidebar. Pick one, or adjust the axes with sliders or numeric values: your preview text and formatting stay as they are while the design moves under them.

The header shows the family name for variable fonts and the current style or axis coordinates, so you always know which style you are looking at. The instance and formatting panels share the sidebar, and clicking the style selector in the header shows or hides the instance panel.

## Color fonts, including variable ones

Color font support is much better across the board, and it now extends to variable color fonts: the palette and the axes at the same time. Pad has rendered color fonts since 2014, when almost nothing else would. It still does it better than the app you are pasting into.

Placeholder glyphs now use nonzero winding fill, so overlapping outlines stay filled instead of punching holes in each other.

## Right-to-left scripts

Arabic, Hebrew and other right-to-left scripts are handled better in Pad 2. If you set RTL text, the line layout and the cursor behave the way you expect them to.

## Glyphs by name

Select a letter, press the `/` key in the preview, then type a glyph name or a character to insert any variant: a swash, a stylistic alternate, a ligature. Glyphs in the picker are drawn with the current instance, so what you choose is what you get.

## Copying, with the format you meant

The Copy button is its own control now, and it offers Bitmap, SVG and PDF. It remembers the format you picked last, and it preserves the font color and the preview layout. If you set your text over a transparent background to check it against a design, that is what lands in the other app.

## What Pad opens, and where it runs

Static and variable OpenType, color OpenType in SVG, `sbix`, `COLR`/`CPAL` and `CBDT`/`CBLC` flavors, Type 1 and multiple-master fonts, WOFF web fonts, Photofont and SVG fonts. It copies Bitmap, SVG and PDF, and exports PNG, SVG and PDF.

On the Mac, Pad 2 is a true universal app, native on Apple silicon and on Intel. It runs on macOS 10.15 and newer, and on Windows 10 and newer. It’s free to use on any number of devices belonging to one household or organization.
