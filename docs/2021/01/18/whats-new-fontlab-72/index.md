FontLab 7.2 was a substantial update, and this 31-minute walkthrough by Adam Twardoch covers the new features methodically. If you want to know what changed and why it matters, this is the most efficient way to find out — a guided tour of the release notes, with live demonstrations.

FontLab 7.2 introduced improvements across drawing, variable fonts, OpenType features, and font export. Twardoch walks through each area in turn: new contour operations, refinements to the element system (FontLab’s approach to reusable glyph components), improvements to the variation panel, and changes to how fonts are exported to UFO, OpenType, and other formats.

The video also covers smaller quality-of-life improvements — keyboard shortcuts, panel behavior, performance — that don’t make headlines individually but collectively make the application faster to use. Twardoch’s commentary explains not just what each feature does but why the design decision was made, which is useful context if you’ve wondered why FontLab works a particular way.

For existing FontLab 7 users, this video is the fastest path from “I saw the release notes” to “I understand what actually changed.” For users considering upgrading, it gives a concrete sense of the pace and direction of FontLab development.
