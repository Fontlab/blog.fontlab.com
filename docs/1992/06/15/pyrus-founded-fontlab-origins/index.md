In 1992, Pyrus North America Ltd. was incorporated to distribute font software from SoftUnion Ltd. of St. Petersburg, Russia. The following year, FontLab 2.0 for Windows became one of the first digital font editors on the platform.

Pyrus North America was the international distribution arm for SoftUnion, a St. Petersburg software house. The arrangement reflected the post-Soviet moment: technical depth in Russia, market access in North America.

In 1993, SoftUnion and Pyrus released FontLab 2.0 for Windows. The font editing market was thin on Windows — the Mac dominated professional type work, and the tools that existed were largely Mac-only. FontLab 2.0 brought Bézier outline editing to Windows users, targeting a then-new and rapidly growing group of computer-based designers.

The software had a predecessor: FontDesigner 1.0, a 1991 Windows application that established the technical foundation. FontLab 2.0 built on that base and expanded it for a broader audience.

Yuri Yarmola led the original SoftUnion programming group and remained the central technical figure through subsequent ownership changes. The St. Petersburg development team that built FontLab in those early years continued working on the product for decades.
