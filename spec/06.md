# Chapter 6 — Site Structure & Navigation

## URL map

The blog lives at the **site root** (`blog_dir: .`). The home page is the blog index. There is no `/blog/` segment.

```
https://blog.fontlab.com/
│
├── /                                   Blog index (paginated, newest first) — IS the home
├── /page/{n}/                          Pagination pages
├── /about/                             About page — who writes here, what it's for
│
├── /{yyyy}/{mm}/{dd}/{slug}/           Individual posts
│
├── /archive/                           Year-based archive index
│   ├── /archive/2013/
│   ├── /archive/2024/
│   └── ...
│
└── /tags/                              Tag index
```

Post URL pattern: `/{yyyy}/{mm}/{dd}/{slug}/`

The archive route is generated automatically by the MaterialX blog plugin. Category pages are disabled, and author profile pages are not enabled; authors render in post metadata only.

## Pages that require source files

| URL | Source file | Notes |
|-----|------------|-------|
| `/` | `src_docs/md/index.md` | Plugin overrides this with the paginated post list. Keep file minimal — it exists to satisfy `nav`. |
| `/about/` | `src_docs/md/about.md` | Condensed company history; ~300–750 words. |

There is no `src_docs/md/blog/index.md` — the blog plugin owns the root index when `blog_dir: .`.

## Navigation structure

The local menu is configured via the Web Component config object (see [chapter 8](08.md)):

```javascript
localMenu: [
  { label: "Blog",     url: "/" },
  { label: "Archive",  url: "/archive/" },
  { label: "About",    url: "/about/" },
]
```

The MaterialX sidebar is suppressed — the site is a flat blog. The `nav:` key in `mkdocs.yml` lists `index.md` and `about.md` only; posts are discovered by the plugin from `src_docs/md/posts/`.

## Home page

The home page **is** the blog index. The plugin renders the paginated post list at `/`. A separate landing page is unnecessary and was rejected to avoid a redundant click between the domain root and the content.

## About page

Condensed from `reference/fontlab-com-oldpub/about/index.html`. Answers:

- What is this blog?
- Who writes here?
- How do I contact FontLab?

Not a full company profile — that lives on fontlab.com.

## What is deliberately absent

**No sidebar.** The site is a blog, not a documentation tree.

**No category pages.** Categories are disabled in MaterialX blog config, and posts do not carry a `categories:` field. Tags remain available for loose discovery.

**No tags page in the main nav.** Tags are configured in the plugin and accessible via the MaterialX tags index, but no top-level link.

**No search results page in the nav.** Search is the loupe icon in the Web Component menu; results render in place.

**No `/blog/` prefix.** The blog is the site, not a section of it. Old `/blog/...` URLs from the previous spec do not exist and never shipped.
