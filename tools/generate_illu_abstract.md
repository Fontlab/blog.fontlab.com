# Abstract Illustration Prompt

Saul Steinberg / Paul Rand single-weight pen-line illustration. ONE continuous loose ink line drawing on a PLAIN WHITE BACKGROUND. Pure black ink line only — no fill, no shading, no halftone, no hatching, no color, no gray, no texture, no paper grain, no border, no signature, no text. The line is confident, slightly imperfect, hand-drawn, charming, economical. Generous negative space. Composition fills the square but keeps the subject central with breathing room. Square 1024x1024. The result must read as iconic at thumbnail size and retain charm at full size. NEVER include any letter, word, label, or signature in the image. ABSTRACT / SYMBOLIC interpretation. Translate the post's underlying idea into a metaphor, a gesture, or a symbol — never literal. Quiet, lyrical, slightly mysterious. The viewer should sense the MOOD of the post. {}
