## LinkedIn variant

Conventional variable-font specimens show a handful of frozen instances — 100, 400, 900 — and ask the viewer to imagine the rest. Vexy Lines assigns a different variable-font instance to every glyph, reading each choice from the brightness of a source image, so one line of text traverses the entire designspace, every interpolated step in order. It works on any axis you have built — weight, width, optical size, grade, contrast — and the per-glyph engine is scriptable via a CLI, an MCP server, and a Python library, so you can batch specimens overnight or render frame-by-frame animations.
