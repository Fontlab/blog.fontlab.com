# DTL OTMaster 7.9 available now

By [Thomas
Phinney](https://www.fontlab.com/author/thomaswphn846554/ "Thomas Phinney")
on 2018-11-22 in
<a href="https://www.fontlab.com/news/" rel="category tag">News</a>

The technical OpenType editor <span class="caps">DTL</span> **OTMaster**
developed by Dutch Type Library (<span class="caps">DTL</span>) and
<span class="caps">URW</span> Type Foundry is now available in **version
<span class="numbers">7</span>.<span class="numbers">9</span>**. The new
version brings support for variable OpenType fonts, an all-new Proofing
Tool for printing and creating <span class="caps">PDF</span> specimens,
and many detailed improvements.

With OTMaster, you can inspect, troubleshoot and modify OpenType and
TrueType fonts in a non-invasive way — in all their flavors, including
variable fonts, color fonts, <span class="caps">TTC</span> collections,
<span class="caps">WOFF<span class="numbers">2</span></span> web fonts,
and CID-keyed <span class="caps">OTF</span> fonts. You can view and
change OpenType Layout features, edit low-level OpenType font tables,
and fix bugs or problems. With OTMaster’s Glyph Editor, you can import
a monochrome <span class="caps">EPS</span> or
<span class="caps">SVG</span> drawing, ornament or logo, and add it as
a new glyph or replace an existing glyph in a font.

## New in OTMaster 7.9

- **OpenType Font Variations **support: New Font Variation Viewer
  & instances editor. Support for *fvar, gvar,
  <span class="caps">CFF<span class="numbers">2</span></span>,
  <span class="caps">STAT</span>, <span class="caps">HVAR</span>,
  <span class="caps">MVAR</span>, meta* tables. Show instances and
  isomorphic compatibility in Side by Side Viewer. Variation support in
  the Glyph Viewer, Text Viewer and Glyph Editor.
- **Proofing Tool**: Print or export to <span class="caps">PDF</span>
  all or selected glyphs (one or multiple per page) of the current or
  all open fonts, or specimens with custom text. Show, hide or customize
  the outline, points, glyph and font metrics, labels and other details.

## Improved in OTMaster 7.9

- **Side By Side Viewer: **Print, show variation instances, only show
  glyphs that are non-interpolable or differ in width.
- **Table Comparator: **Make tables consistent across a family, enhance,
  or remove entries.
- **<span class="caps">GPOS</span>/<span class="caps">GSUB</span> Table
  Viewer: **When editing mark attachment visually, hold Shift-drag to
  move marks horizontally, hold Shift+Alt to move them vertically
- **OpenType tables: **Support
  for *<span class="caps">OS</span>/<span class="numbers">2</span>* table
  version
  <span class="numbers">1</span> – <span class="numbers">5</span>,
  auto-calculate new fields when upgrading table version. Show X,Y
  positions in *glyf* table comments.
- **Consistency Checker:** *use\_typo\_metrics* checkbox
- **Import/Export: **Export fonts to <span class="caps">UFO</span>
  format. Export instances from variable fonts to
  <span class="caps">URW</span> <span class="caps">QQ</span> or
  <span class="caps">BE</span> files. Export
  <span class="caps">AFM</span> with original
  <span class="caps">UPM</span>.
- **Text Viewer: **Edit glyph metrics (advance width). Easier handling
  of texts.
- **Glyph Editor: **Point List panel. Tabs moved from bottom to top.
  Reset to maximum Em-square. Antialiasing. Center vertically in Em
  square. Edit glyph metrics. Point numbering (no virtual anchor points
  in <span class="caps">TT</span> fonts). Marker Size, Fill Anchor
  Points in Preferences.

## OTMaster system requirements

### Windows

- **OTMaster
  <span class="numbers">7</span>.<span class="numbers">9</span> for
  Windows** is a <span class="numbers">32</span>-bit app that runs on
  Windows <span class="numbers">7</span> and newer, including Windows
  <span class="numbers">10</span> (either the
  <span class="numbers">32</span>- or the
  <span class="numbers">64</span>-bit version).
- **To install the app: **After unzipping the downloaded file, copy
  the *<span class="caps">DTL</span> OTMaster
  <span class="numbers">7</span>.<span class="numbers">9</span>* folder
  into your *C:\Program Files* folder, navigate to *C:\Program
  Files\\<span class="caps">DTL</span> OTMaster
  <span class="numbers">7</span>.<span class="numbers">9</span>\Program
  Files*, right-click *otm.exe* and choose *Send To &gt; Desktop (create
  shortcut)*.
- **To run the app: **Double-click *otm* or *otm.exe — Shortcut*on your
  Desktop.

### macOS / Mac <span class="caps">OS</span> X

- **OTMaster
  <span class="numbers">7</span>.<span class="numbers">9</span> for
  Mac** is a <span class="numbers">64</span>-bit app that runs on
  Mac <span class="caps">OS</span> X <span class="numbers">10</span>.<span class="numbers">10</span>
  Yosemite or newer, including macOS
  <span class="numbers">10</span>.<span class="numbers">14</span>
  Mojave.
- **To install the app: **Double-click the downloaded
  <span class="caps">DMG</span>. Drag *<span class="caps">DTL</span>
  OTMaster
  <span class="numbers">7</span>.<span class="numbers">9</span>.app* into
  your */Applications* folder.
- **To run the app: **When you start the app for the first time,
  navigate to the *Applications* folder,
  Ctrl+click *<span class="caps">DTL</span> OTMaster
  <span class="numbers">7</span>.<span class="numbers">9</span>.app* and
  choose *Open*. Click *Open*. Subsequently, just double-click the
  app icon.

## Thomas Phinney

Thomas Phinney was CEO of FontLab until 2019, when he retired from
FontLab to pursue his font detective work and type design. Previously he
worked at Extensis (web fonts and font management tools) and Adobe (as
product manager for global fonts and typography). Thomas is also a
teacher, writer, and consultant on fonts and typography. He has been
consulted by Apple, Adobe, Microsoft, Oxford University Press, a “big
three” US auto maker, the US Treasury Department, and PBS “History
Detectives,” among others. He teaches type design with Crafting Type and
has been a repeat guest lecturer for MA Typeface Design at the
University of Reading. Since 2004 he has been a board member of ATypI,
the international typography association. His typeface Hypatia Sans is
an Adobe Original with over 3000 glyphs per font.
