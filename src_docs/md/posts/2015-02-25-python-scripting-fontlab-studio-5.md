Automation unlocks the real power of a professional font editor, and this 70-minute
tutorial with Adam Twardoch is the definitive introduction to Python scripting inside
FontLab Studio 5. It covers the scripting environment, the FontLab object model, and
practical examples that go well beyond “hello world.”

<!-- more -->

[![Basics of Python Scripting in FontLab Studio 5](../media/fontlabtv-QCSKRYZ1Qko.jpg)](https://www.youtube.com/watch?v=QCSKRYZ1Qko)

FontLab Studio 5 exposed its internals through a rich Python API, letting type designers
write scripts to automate repetitive tasks — batch-transforming glyphs, generating
metrics, manipulating anchors, or building entire font families from a master.
This tutorial walks through that API from the ground up.

Twardoch starts with the built-in macro editor and the Python console, then moves
through the object hierarchy: the application object, font objects, glyph objects,
layers, contours, and nodes.
Each level is demonstrated with short scripts you can run immediately, so the tutorial
functions as both a conceptual overview and a practical reference.

The scripting model shown here laid the groundwork for the FontLab 7 scripting API. Many
of the patterns — iterating over glyphs, reading and writing metrics, working with
contour nodes — carry over directly, making this tutorial useful even for users who have
moved to the current version of FontLab.
