November 2012 saw a version split in FontLab Studio 5: a new 5.2 release for Windows and a 5.1.3 maintenance update for Mac.

<!-- more -->

FontLab Studio 5.2 for Windows introduced new features to the Windows build, while Mac users received FontLab Studio 5.1.3 as a bug-fix update. The full Windows 5.2 feature set — including 65,535-glyph OpenType support and FEA syntax 2.5 — was documented with the December 2013 release of FontLab Studio 5.2.1 for Windows.
