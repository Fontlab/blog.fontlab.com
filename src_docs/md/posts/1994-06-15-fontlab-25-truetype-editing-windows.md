FontLab 2.5 for Windows, released in 1994, added TrueType font editing to the existing PostScript Type 1 capabilities — putting both major outline formats under one roof on a platform where that combination had not previously existed.

<!-- more -->

SoftUnion developed and Pyrus released FontLab 2.5 for Windows in 1994. The defining addition was TrueType outline editing: users could now open, modify, and generate TrueType fonts directly, alongside the PostScript Type 1 work the 2.0 release had enabled.

At the time, TrueType was Microsoft and Apple's answer to Adobe's Type 1 format. The two formats used different mathematical representations for curves — cubic Bézier splines in Type 1, quadratic B-splines in TrueType. Supporting both required handling two distinct curve types in the same editor, which FontLab 2.5 did.

The release also bundled two companion utilities: ScanFont, for converting scanned images into font outlines through autotracing, and FindFont, for locating fonts by characteristics on disk. Both shipped in 1994 alongside the 2.5 update.

The combination of Type 1 and TrueType editing in a single Windows application distinguished FontLab 2.5 from contemporaries and established the multi-format approach that remained a core principle of the product line through subsequent generations.
