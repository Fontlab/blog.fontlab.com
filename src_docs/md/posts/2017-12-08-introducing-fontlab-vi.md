FontLab VI was a ground-up rewrite of the professional font editor, and this two-minute announcement video captures the moment of its release. It highlights the new design philosophy — a single application for creating, editing, and exporting fonts in any format — and previews the tools that would define a new generation of FontLab.

<!-- more -->

[![Introducing FontLab VI](../media/fontlabtv-2bEIm8lo2OA.jpg)](https://www.youtube.com/watch?v=2bEIm8lo2OA)

FontLab VI (later renamed FontLab 7 and then FontLab 8) represented a complete departure from FontLab Studio 5. The underlying architecture was rewritten, the interface was redesigned, and a new set of drawing tools — Power Brush, Rapid pen, live corner operations, variable font masters — were built in from the start rather than bolted on.

The video shows the application in motion: fluid Bézier editing, real-time preview of variable font instances, color font handling, and the new glyph window layout. These features addressed pain points that had accumulated over years of FontLab Studio 5 use, and they made FontLab VI the first version of the software genuinely competitive with newer alternatives that had emerged in the intervening decade.

For anyone trying to understand how FontLab evolved from Studio 5 to the current release, this short video is the clearest single-frame snapshot of where the transition began.
